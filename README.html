FEATURES

Focused controls, not a generic dashboard.

PowerDeck exposes a control only when the native daemon can discover, validate and verify the corresponding kernel interface.

01

Battery

Firmware charging modes, custom thresholds, active-mode discovery, read-back verification and rollback.

  • Express / Standard / Adaptive / Custom
  • 50–95% start threshold
  • 55–100% stop threshold
02

Thermal

Kernel platform profiles plus low-overhead CPU, GPU and fan telemetry.

  • Cool / Quiet / Balanced / Performance
  • Intel RAPL and Linux perf fallback
  • Read-only hwmon fan RPM
03

Battery Saver

A user-level native policy that coordinates display, CPU and device savings without keeping the GUI open.

  • Brightness + refresh rate
  • Power + thermal profiles
  • Turbo, P-state, keyboard and audio

ARCHITECTURE

Privilege stays behind D-Bus.

The GUI never runs as root. System writes are authorized with Polkit, validated by Rust and verified against hardware state.

BUILD & INSTALL

Native from source today, package release next.

The repository already contains an Arch PKGBUILD. A public prebuilt package has not been published yet.

Arch / CachyOS build dependencies

sudo pacman -S --needed \
    rust cmake ninja qt6-base \
    gcc pkgconf polkit

Full native quality gate

cd ~/Projects/PowerDeck
./native/scripts/native-check.sh

Development install

cd ~/Projects/PowerDeck
./native/scripts/dev-install.sh

Runtime sanity

powerdeckctl status
powerdeckctl telemetry --json
