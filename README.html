PowerDeck

A capability-driven Linux power manager for Dell laptops, built around verified hardware writes and ownership-aware restore.

What PowerDeck does

PowerDeck keeps the graphical application unprivileged. Hardware changes are validated by a system service, written transactionally, read back, and rolled back when verification fails.

Area Current state
Thermal profiles Verified on the target laptop
Battery charging Combined and split sysfs layouts supported
Battery Saver Manual switch and AC transition automation
Restore behavior Restores only values PowerDeck still owns

Focused controls

Battery

Reads battery health, AC state, bracketed charge_types, charging modes, and custom thresholds. Writes use snapshot, verification, and exact raw-token rollback.

Thermal Mode

Applies quiet, cool, balanced, and performance through the Linux platform-profile class.

Battery Saver

Coordinates brightness, refresh rate, OS power profile, thermal mode, Intel P-state limits, keyboard light, and optional audio mute.

Install the local candidate

PowerDeck depends on native Linux services as well as Python packages. pip cannot install GTK, Libadwaita, Polkit, brightness tools, or power-profiles-daemon.

Required on Arch/CachyOS

sudo pacman -S --needed \
    git \
    python \
    python-dbus-next \
    python-gobject \
    gtk4 \
    libadwaita \
    polkit \
    brightnessctl \
    power-profiles-daemon

Optional feature dependencies

Package or tool Feature
niri Internal-panel refresh-rate switching
wireplumber / wpctl Optional audio mute and restore

Missing optional tools do not prevent the application from opening. PowerDeck reports or skips only the affected Battery Saver action.

Clone and install

git clone https://github.com/minh23102011/fork-dell-power-manager.git
cd fork-dell-power-manager

./scripts/check-dependencies.sh

python -m venv .venv
source .venv/bin/activate.fish
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"

deactivate
./scripts/install-local-v0.1.sh
./scripts/v0.1-check.sh
./powerdeck

The installer repeats the required package installation with pacman -S --needed, then configures powerdeckd, system D-Bus, Polkit, the user agent, and the desktop entry.

Current limitations

  • Dell Inspiron 15 3530 is the only real-hardware validation target.
  • Fan curves, direct fan control, undervolting, and per-app rules are outside v0.1.
  • The HTML controls are a simulation, not a browser control surface.
  • The current local Polkit policy should be tightened before a broad public release.
